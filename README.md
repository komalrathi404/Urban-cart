## 📌 Project Overview

**Urban Cart** is a fully functional e-commerce web application built as the final capstone project for the Web Development Internship at **ApexPlanet Software Pvt. Ltd.** It brings together everything from the earlier tasks — responsive layouts, DOM manipulation, form validation, and localStorage — into one complete, production-style shopping experience: browse, search, filter, add to cart, and check out, all with vanilla HTML, CSS, and JavaScript.


## ✨ Features & Highlights

- **24-Product Catalog Across 6 Categories** — Electronics, Fashion, Home, Beauty, Books, and Sports, each with real product imagery, ratings, and descriptions.
- **Live Search** — Instantly filters products by name, category, or tags as you type.
- **Category Filtering & Sorting** — Filter by category and sort by price (low–high, high–low) or rating.
- **Hero Carousel** — Auto-rotating promotional banners with manual navigation (arrows + dots).
- **Best Sellers & New Arrivals** — Dynamically generated homepage sections based on product rating and recency.
- **Quick View Modal** — Preview any product's full details without leaving the current page.
- **Shopping Cart with Persistence** — Add, update quantity, and remove items; cart state is saved via `localStorage` and survives page refreshes.
- **Animated Cart Feedback** — A toast notification and a bounce animation on the cart badge confirm every add-to-cart action.
- **Full Checkout Flow** — A validated shipping form (name, email, phone, address) leading to an order summary and a confirmation page.
- **Mobile-First Responsive Design** — A hamburger navigation menu and a fluid product grid (`auto-fill` grid) that adapts cleanly from mobile to desktop, with no orphaned single-item rows.
- **Accessibility Considerations** — Keyboard-visible focus states, a skip-to-content link, and `aria-label`s on icon-only controls.
- **Loading States** — Skeleton-loader animations while product results render, for a smoother perceived experience.
- **SEO Basics** — Meta descriptions, Open Graph tags, and a favicon on every page.

## 🛠 Tech Stack Used

- **Markup:** HTML5 (semantic structure across 6 pages)
- **Styling:** CSS3 (Flexbox, CSS Grid with `auto-fill`, media queries, keyframe animations)
- **Interactivity:** Vanilla JavaScript — DOM manipulation, `localStorage` for cart persistence, `IntersectionObserver` for scroll-reveal animations, form validation with regex
- **Version Control:** Git & GitHub (command-line workflow with structured commit history)
- **Deployment:** GitHub Pages
